THE BACKLOG

1. **Register ship arrivals**  
   Done when an operator can record a ship’s unique ID, name, and arrival time.

2. **Manage docks**  
   Done when an operator can add docks and see whether each is available or occupied.

3. **Dock a ship**  
   Done when an operator can assign a ship to an available dock without double booking.

4. **Record ship departures**  
   Done when departing a ship records its departure time and frees its dock.

5. **View port status**  
   Done when an operator can see all current ships, their docks, and available docks.

6. **Search for ships**  
   Done when an operator can find a ship by its ID or name.

7. **Edit ship details**  
   Done when an operator can update a ship’s details and see the saved changes.

8. **View visit history**  
   Done when an operator can view previous visits with arrival and departure times.
