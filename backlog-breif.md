THE BACKLOG

1. **Register ship arrivals**  
   Done when an operator can record a ship's unique ID, name, arrival time, cargo capacity, and the number of cargo units on board.

2. **Manage docks**  
   Done when an operator can add docks with a maximum ship size and hourly rate, and see whether each is available or occupied.

3. **Dock a ship**  
   Done when an operator can assign a ship to an available dock that fits its size, without double booking.

4. **Manage storage areas**  
   Done when an operator can add storage areas with a capacity in cargo units and a daily rate per unit, and see how much of each is used and free.

5. **Unload cargo**  
   Done when an operator can move cargo units from a docked ship into a storage area, without exceeding what the ship carries or what the storage area can hold.

6. **Load cargo**  
   Done when an operator can move cargo units from storage onto a docked ship, without exceeding the units in storage or the ship's remaining capacity.

7. **Enforce cargo rules**  
   Done when the system blocks cargo movements that break port rules, such as moving cargo to or from a ship that is not docked.

8. **Record ship departures**  
   Done when departing a ship records its departure time, frees its dock, and calculates the docking fee from time spent at the dock.

9. **Calculate storage fees**  
   Done when the system charges cargo units kept in storage beyond a free period, and shows the fee owed for each ship's cargo.

10. **View port status**  
    Done when an operator can see all current ships and their docks, available docks, and the fill level of every storage area.

11. **View visit history**  
    Done when an operator can view previous visits with arrival and departure times, cargo units loaded and unloaded, and fees charged.
